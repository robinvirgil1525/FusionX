# Campus Hub: Floor Manager & Attendance 🏫📊

[Campus Hub](https://robinvirgil1525.github.io/FusionX/) is an intelligent campus spatial, scheduling, and attendance management web application designed to help students and staff find empty rooms in seconds, track real-time building occupancy, monitor monthly utilization, and manage student or course attendance seamlessly.

---

## 🚀 Key Features

* **💬 Natural Language Room Search:** Ask in plain English (e.g., *"I need an AC room on the ground floor for 2 hours"* or *"Quiet room with a projector"*), and the system evaluates timetables to rank the best options.
* **🗺️ Interactive Live Floor Maps:** Visualize real-time availability across multiple building floors (Ground to 6th floor) with color-coded status blocks (Available, Occupied, Reserved Soon, Recommended).
* **⏱️ Room Timers & Countdown:** Select any room block on the 3D map to view a live countdown to its upcoming classes and check how long it will stay vacant.
* **📊 Analytics & Utilization Dashboard:** Monitor peak occupancy periods, most-frequently used rooms, floor-wise utilization metrics, and projected monthly room usage based on weekly timetable datasets.
* **📝 Attendance Management:** Integrated tools to track and manage class attendance records alongside spatial allocations.
* **📂 Custom Dataset Support:** Easily swap and load custom JSON timetable datasets to adapt the tool to different departments or semesters.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Modern CSS / Tailwind (Dark/Light mode support), JavaScript
* **Architecture:** Client-side timetable processing, natural-language query parser, and spatial mapping modules
* **Hosting:** GitHub Pages ([Live Demo](https://robinvirgil1525.github.io/FusionX/))

---

## ⚙️ Getting Started & Usage

1. Visit the live app: [Campus Hub Live](https://robinvirgil1525.github.io/FusionX/)
2. Switch between **Floor Manager** and **Attendance** modules using the top navigation header.
3. Type or select a quick search query in the AI room finder or inspect live floor occupancy.
4. Click **Load dataset (JSON)** to upload custom schedule files if needed.
